### Flujo de Trabajo
Este directorio contiene la parte móvil del proyecto (**Flutter**). Si deseas ejecutar el prototipo:
1. Dirígete a la carpeta [Frontend/](Frontend/).
2. Ejecuta `flutter pub get`.
3. Ejecuta `flutter run` para iniciar la aplicación.
